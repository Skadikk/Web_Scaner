# Web Directory Scanner 🕵️‍♂️

Простой сканер директорий (папок) на Python. Это мой второй проект, созданный для изучения основ веб-хакинга и работы с HTTP-запросами.

## 🚀 Возможности
- Проверяет наличие скрытых папок и файлов на сайте (например, `/admin`, `/backup`, `/robots.txt`).
- Использует многопоточность (`ThreadPoolExecutor`) для быстрой проверки.
- Маскируется под обычный браузер (User-Agent), чтобы обходить базовые блокировки.
- Сохраняет найденные пути в файл `records.txt`.

## ⚙️ Как использовать
1. Убедитесь, что у вас установлен Python 3 и библиотека `requests`:
   pip install requests

2 Запустите скрипт:
bash
python web_scanner.py

3 Введите URL сайта (например, http://test.com).

4 Скрипт выведет найденные папки в консоль и запишет их в records.txt.

 ⚠️ Предупреждение!!!!!!!!!!!!!!!
Этот инструмент создан исключительно в образовательных целях. Не используйте его для сканирования сайтов, которыми вы не владеете и на тестирование которых у вас нет разрешения. Несанкционированное сканирование веб-ресурсов является незаконным.
